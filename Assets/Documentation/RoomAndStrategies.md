# 房间交互与金融技巧版本

## 试玩入口

打开 MainGame，点击 Play 随机开局。游戏仍为 30 天，英文界面。

- 点击冰箱：查看还能吃几天、今天是否已吃过、今晚生活费。
- 点击墙上日历：查看房租、家庭生活费、生日、已确认收入和主动设置的提醒/愿望单回访。购物、临时加班等尚未遇到的事件不会提前显示。点击日期看详情，左右箭头切换月份。收入先在早晨到账，生活费和房租在 End Day 结算。
- 点击桌上 Money Tracker：查看逐笔现金流水、决策记录、待到账收入和应急缓冲目标。
- Money Tracker 的 Reserve 按钮可为下一次房租预留资金；Release 可解除。总余额不变，未分配资金减少。主动消费使用未分配资金，必要生活费可能动用预留，交租自动消耗对应预留。预留不是收入或真实支付，不会额外产生现金交易。
- 冰箱只展示库存与今晚生活费，不提供采购按钮。采购通过日志事件进行；没有库存仍可正常生活，食物每天扣 $20，另扣必要支出。
- 点击右下角 Journal：处理当天事件，再 End Day。多阶段事件必须完成所有阶段才能结束当天。
- 事件正文只保留短情境；可点击 Why it matters 阅读技巧、来源与适用边界。日历和冰箱在日志中也有快捷入口。

房间图片随窗口拉伸铺满，物体按钮使用同一父对象中的相对位置，避免窗口变化后点击区域偏离图片；文字由独立的 TextMesh Pro 组件渲染。极宽或极窄的窗口会改变插画比例。物体及下面的标签都可点击。

字体清晰度检查：Game 预览关闭 Low Resolution Aspect Ratios，Scale 使用 1x；放大 Game 面板后检查实际画面。Canvas 使用屏幕空间叠加、按屏幕尺寸缩放和像素对齐。预览倍率和低分辨率选项属于本机编辑器设置，不会随 Git 同步到同学电脑。

## 六类技巧如何进入玩法

| 技巧 | 首次/主要日期（游戏天数） | 玩家实际操作 |
|---|---|---|
| 比较单位价格 | 1、8、23 | 比较整笔价格、可供食用天数，以及交租前能否承担预付款 |
| 出门设定消费上限 | 2 | 先带 $20 / $40 现金或用卡，再选 $12 午餐、$30 午餐加纪念品、离开；现金上限限制本次消费 |
| 留意饥饿状态 | 4 | 有储备时可先吃当日份额，再在采购环节决定是否加买 $12 零食；吃过的份额晚上不重复消耗 |
| 购买前暂停 | 9，次日跟进 | $30 耳机现在买、列入愿望单、放弃；选择等待后，第 10 天工作事件完成后再考虑购买 |
| 先查库存、列清单 | 15 | 先选择是否查看冰箱和准备四天清单，再选买两天、四天或暂不采购 |
| 为目标设提醒 | 6、可选 16、24 | 设 $40 应急缓冲目标；可让日历在生活费到账后提醒，再选择记下 $20 / $40 或不预留 |

当前日程有 17 个固定事件起点；部分事件有第二阶段，提醒和愿望单回访由前面选择触发。这是六种技巧的首批实现，尚不是每种技巧三个独立情境的完整事件库。

最终版的核心练习为房租预留、根据库存采购、安排到账时间与休息。第一天的采购强调交租前保留现金，第八天强调生活费到账后的安排，第二十三天强调核对先前购买的库存。其他小技巧是辅助内容。结局只给出最多三条实际记录支持的回顾，包括未到账工资、生活费动用预留、已有库存时的采购、逐日餐费或工作恢复安排；不把某项消费直接认定为错误，也不声称未经模拟的选择必然能避免失败。

现金不产生奖励、提现费或隐藏消费。现金上限是明确的原型规则，不等同于复现真实心理效应。饥饿不会强制玩家额外花钱；当前通过情境和可选加购练习识别诱因。等待不保证降价。检查库存/清单主要提供信息帮助。应急缓冲只是可修改的计划，仍包含在余额内，没有真正转入另一账户，也不会锁住资金。因此，这版实现了操作机会，但不能据此证明玩家学会或改变真实消费习惯；后续需观察其是否主动使用这些工具。

## 组件与维护

### 当前收入、打工与心情数值

- 本局角色每周收到 $540 家庭生活费，第 8、15、22、29 天早晨到账；额外打工由玩家选择。
- 短工当天到账 $90，心情 -12；长工三天后到账 $160，心情 -24。连续四天内再次打工额外 -6；按钮显示包括惩罚和上下限的实际变化。
- 免费下午恢复 8；普通休闲活动分别为 $35：一份食物、心情 +30，$20：两份食物、心情 +16，免费：心情 +5。
- 朋友生日：$35 聚餐提供一份食物、心情 +10；$20 带菜提供两份食物、心情 +5；免费发祝福但不参加，心情 -5。不参加不属于恢复活动，不清除连续工作状态；参加的两种活动可清除。自己的生日拟定为 +15/+10/+5，当前没有该事件。
- 恢复活动会清除连续打工状态；购买耳机、零食和纪念品不清除它。
- 心情从 65 开始，上限 100，25 及以下警告，0 结束。不自动每日下降，也不因单纯省钱扣心情。
- 上述数值只用于开发和后台计算。玩家看到的是用户手绘的四张 64px 表情：80–100 Happy、60–79 Calm、40–59 Tired、1–39 Exhausted；0 仍结束。右上角不再显示数字或进度条，日志、选项、反馈及结局使用定性状态；Exhausted 阶段会提示安排恢复。
- 图像保存在 Assets/Art/Mood，使用 Point 过滤、无压缩、无 Mip Maps；MoodCard 在右上角显示原图及状态文字。没有改动用户的画像。分档映射在 MoodSystem，显示引用在 GameUI。
- 第 8 天大包装调整为 $90 / 六天食物，保留 $36 / 两天和暂不采购。最低单位价格与交租前保留现金之间需要取舍。
- 房间安装工具一次性迁移旧数值；balanceRevision 1 对应打工调整，2 对应朋友生日调整，之后保留 Inspector 调整。Is Recovery 用于显式标记休息/恢复选项，与单纯增加心情区分。
- balanceRevision 4 删除冰箱采购按钮，加入第11天零食计划并更新采购说明。GamePlanning 管理房租预留、食物优惠和结局回顾；RoomInterface 管理库存展示。应急缓冲目标 PlannedReserve 仍是提醒目标，与实际影响未分配现金的 RentReserve 分开。

GameSystems 保留 FinanceRules、MoodSystem、GameEventSchedule、EconomyManager、GameManager，并新增 StrategySystem。Canvas 新增 RoomInterface，负责日历、冰箱和可选说明。房间、按钮和两个新面板都是保存到 MainGame 场景的 Unity UI 组件。

- 固定事件在 GameEventSchedule 的 Events 中调整：Day、Id、Title、Body、Choices、Tip Key。
- 两阶段和条件事件在 StrategySystem.FollowUp / OverrideDay 中定义。现金上限、吃饭、清单、提醒等行为由选项 Action 关联；不要随意改动有代码关联的 Id。
- 当前第二阶段商品价格、目标金额和第 10/16/24 天逻辑在 StrategySystem 中，不是全部 Inspector 可调。修改日程时须同时核对该脚本及 RoomInterface 的相关日历标记。
- 房间 UI 修复菜单：Tools > Financial Game > Install Room and Strategy Events。仅在非 Play 状态使用；正常试玩不必运行。首次迁移增加技巧事件，再次执行保留已有事件数据并重建布局。旧安装菜单会转到本安装器，避免覆盖房间。
- 场景中主界面旧 FoodText 和两个旧导航按钮已禁用，新热点替代它们。
- 仍无跨局存档、随机事件池或不同房间。开局只有资金档位变化，当前以可验证的一月日程为主。

## 验证记录

Unity 6000.3.9f1 编译和规则测试通过。三个开局各采样 500 条随机路线，通关分别为 22、68、82 条；每个开局都有已验证的规划通关路线。这是固定种子下的程序采样，不是玩家测试、全组合枚举或学习效果证据。

Validate Choice Tradeoffs 检查三种固定点法在三个开局的结果：优先最低当前费用、费用相同时优先心情恢复，在第 12–13 天因现金不足结束；总接最高收入的长工，在第 10 天心情耗尽；总接短工且只选免费社交恢复，在第 17 天心情耗尽。这些是特定基线，不能推断所有简单策略都失败。另用独立情境验证：较小采购可补足库存缺口并保住房租，最低单位价格的大包装可能挤占房租；当天到账的小收入能交租，三天后到账的大收入不能。已验证规划路线仍能通关，付费活动不被设为必选。

Validate Room Rules 检查多阶段事件、重复点击保护、现金上限、食物只消耗一次、余额与流水一致、心情、待到账收入及重开。Validate Room Live UI 在新开局的 Play 模式运行，调用实际场景按钮完成 30 天规划路线，检查日历/冰箱/解释页面切换、文本溢出、账本滚动和重开。会替代当前这局，结束后回到新开局。已人工点击检查房间热点、生日和房租同日的日历显示。

FinalGameplayValidation 另检查预留/解除不改变总余额、部分预留、主动购买限制、必要生活费动用预留、交租不重复扣款、采购库存与交易以及重开。MoodPresentationValidation 在保存的场景中检查真实预留/解除和库存页面，再走完整 30 天路线并检查文字布局。随机路线样本只使用事件选项，不包含预留操作，因此不能代表最终版全部玩法的通关率。

## 零食计划与交租前现金（当前规则）

- 第11天一次性机会：现在支付 $36，第12至26天（含）每日有伙食扣款时少扣 $3，即 $20 变 $17。没有续费或自动续订。
- 有库存或已吃过当天食物，伙食费仍为 $0，不返现、不累加未使用优惠，不推迟到期。其他每日必要支出不受影响。
- 最大节省 $45；需要12个实际付费伙食日才收回 $36 成本。第12天交租，因此长远便宜也可能导致眼下交不起租。金额是游戏参数，不是“零食被研究证实能省钱”的主张。
- 选择前可查看库存、现金、房租和生活费。选项只检查当前可支付的未分配现金，不替玩家禁止所有有风险的选择。预留房租仍可以阻止动用预留，解除后由玩家自己判断。
- 验证：购买当天无优惠；次日起15天生效，第16个后续日失效；库存无返现；重新开始清空；资金充足时最大省 $45；独立情境 $560、明日房租 $500、无库存时，不买可交租，付 $36 后交租失败。完整规划路线仍可在三个开局通关。以上均为程序检查，不能证明学习效果。
