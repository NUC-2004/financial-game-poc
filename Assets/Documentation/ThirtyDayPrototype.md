# 30 天原型：组件与调参说明

> 本文保留房间升级前的基础规则和十二事件版本记录。当前新增技巧、多阶段事件、日历与冰箱；最新功能、测试与维护入口以 [RoomAndStrategies.md](RoomAndStrategies.md) 为准。以下旧 UI 测试和旧安装说明仅作历史记录。

本版用于测试预算、现金流与休息安排之间的取舍。具体金额、心情变化和失败阈值均为游戏设计参数，不是澳大利亚生活成本调查结果，也不是心理健康模型。游戏尚未证明教育效果。

## 在 Unity 中使用

打开 `Assets/Scenes/MainGame.unity`，选择 Hierarchy 中的 `GameSystems`。

| 组件 | 用途 | 常用 Inspector 参数 |
|---|---|---|
| Finance Rules | 财务与日期规则 | Run Days、Opening Balances、Daily Food、Daily Essentials、Rent、First Rent Day、Rent Interval、Wages、First Pay Day、Pay Interval |
| Mood System | 心情状态和连续工作惩罚 | Starting Mood、Warning Level、Repeat Work Penalty、Repeat Work Window |
| Game Event Schedule | 按天安排事件 | Events → Day、Title、Body、Choices；每个选项包含 Cost、Food Days、Income、Delay Days、Mood、Is Work |
| Economy Manager | 逐笔交易与余额 | 由游戏运行时记录 |
| Game Manager | 一局游戏的流程 | 引用上述组件；管理结算、失败与重新开始 |

事件金额只改 Choices 中的数字，按钮会自动生成价格、到账日期、食物和实际心情变化。文案若提及特定日期或账单，修改日程后应一并检查。每一天最多一个事件，每个事件恰好三个选项，至少一个不需要预付款。

场景已经安装好组件。修复丢失的界面绑定时，可在非 Play 状态打开 MainGame，使用 `Tools > Financial Game > Install 30 Day Components`。该操作会重新布局记账本和日志，正常调参不需要反复执行。已有财务、心情和事件参数不会被重设。

## 当前规则

- 2026-09-11 开始，共 30 天。开局随机为 $740、$780、$820。
- 无储备食物时，食物 $20/天，其他必要支出 $10/天。有食物时每晚消耗一份，免去当晚的 $20。
- 房租每 7 天 $500，第一次在第 5 天；本局交租日为第 5、12、19、26 天。
- 固定工资每 7 天 $540，第一次在第 8 天；本局发薪日为第 8、15、22、29 天。
- 每日顺序：早晨工资和已到期的事件收入到账 → 做选择 → End Day 扣食物、其他生活费 → 交当日房租。
- 待到账收入显示在记账本中，不计入可花余额。无法承担全额生活费时不做部分扣款；无法交租时，当天生活费已扣除。
- 心情初始 65，上限 100，不自动每日下降。25 及以下警告，降到 0 时结束本局。
- 距离上一次额外工作不超过 4 天时，再工作额外扣 6 心情；选择恢复活动会清除这个连续工作状态。购物不会清除状态。
- 按钮显示的是含重复工作惩罚、且经过 0–100 限制的实际心情变化。会降至 0 的选项明确标记 ENDS RUN。
- 拥有足够现金只表示能支付选项的当前价格，不表示还能付清今晚账单。允许玩家作出有风险的选择。
- 储备食物叠加且不腐坏，不会在结束时退钱。本版未模拟健康、学业或关系数值。
- 每局结束可看账本与决策历史；New Run 重置余额、日期、食物、心情、历史和待到账收入。未加入跨局存档。

## 事件日程

| 天数 | 事件 | 取舍 |
|---|---|---|
| 1 | 采购 | $64/4天、$36/2天、保留现金 |
| 3 | 兼职与休息 | 今天 $80 / 心情 -10；三天后 $140 / 心情 -18；免费休息 +12 |
| 7 | 兼职与休息 | 同类机会，可能触发连续工作惩罚 |
| 8 | 采购 | 当日固定工资已到账，但第12天需要交租 |
| 10 | 兼职与休息 | 较高收入在第13天到账，晚于第12天房租 |
| 12 | 朋友生日 | $35/心情+24/食物1天；$20/+12/食物2天；免费通话休息+6 |
| 15 | 采购 | 比较现有食物与第19天房租 |
| 17 | 兼职与休息 | 较高收入在第20天到账，晚于第19天房租 |
| 21 | 兼职与休息 | 权衡心情与后续收入 |
| 23 | 采购 | $80/5天、$36/2天、保留现金 |
| 25 | 恢复活动 | $35/心情+24/食物1天；$20/+12/食物2天；免费散步聊天+6 |
| 27 | 最后一次兼职或休息 | 收入与月底状态取舍；延迟收入在第30天到账 |

复用兼职的规则是为了比较不同现金流处境，而不是靠隐藏随机奖励改变答案。故事采用短句和冷幽默，选项效果保持直白。

## 验证与下一步

`Tools > Financial Game > Validate 30 Day Rules` 使用临时组件运行固定随机种子的路线采样，检查每日结算、重复领取、到账日期、食物、心情、重开与账目合计。测试不会改动当前玩家的一局游戏。

自动路线不是真人测试，通关比例不是实际玩家通关率。下一步请让试玩者解释选择前的计算，观察他们是否查看交租日期、是否把待到账收入当成现款，以及是否会在不同开局改变策略。再根据反馈调整难度。

当前验证：Unity 6000.3.9f1 编译通过。固定随机种子下，三个开局分别完成 139/1000、252/1000、381/1000 条随机路线。场景中的按钮回调已完成一条 30 天规划路线，验证心情、12次选择、文本边界、长账本滚动、重复点击保护和重开；该路线结束心情为71。也已用实际鼠标检查采购反馈。

在刚进入 Play 的第一天，可运行 `Tools > Financial Game > Validate 30 Day Live UI` 重做界面检查。它会完成并替换当前这一局，最后回到新的第一天；规则测试则使用独立临时对象。
